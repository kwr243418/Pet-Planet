일정표 3주차 FE1 할 일을 모두 반영했어요. 자동 점검: 단위·통합 테스트 15개, 시연 시나리오 28개 항목 통과.

## Day 11 · 반응형 UI 다듬기, 로딩 State 및 예외 처리 화면 개선

| 항목 | 내용 | 파일 |
|---|---|---|
| 페이지 이동 시 맨 위로 | 다른 화면으로 가면 스크롤을 맨 위로. 같은 화면에서 필터만 바꿀 때는 그대로, `#reviews` 같은 앵커는 그 위치로 | `components/layout/AppChrome.jsx` `ScrollToTop` |
| 전역 오류 화면 | 화면 코드에서 예기치 못한 오류가 나도 흰 화면 대신 "다시 시도 / 홈으로" (다른 화면으로 가면 자동 복구) | `AppChrome.jsx` `ErrorBoundary` |
| 오프라인 안내 | 인터넷이 끊기면 화면 위에 테라코타 안내 띠 | `AppChrome.jsx` `OfflineBanner` |
| 브라우저 탭 제목 | 화면마다 "홍대입구역 주변 장소 · PET PLANET", 장소 상세는 장소 이름 | `hooks/usePage.js` `usePageTitle` |
| 장소 상세 로딩 | 빙글 도는 표시 대신 실제 화면 모양 그대로의 회색 자리(스켈레톤) | `pages/PlaceDetail.jsx` `DetailSkeleton` |
| 사진 깨짐 대체 | 장소 사진 주소가 깨지면 카테고리 단어(CAFE 등)로 자동 대체 | `components/place/PlaceCards.jsx`, `PlaceDetail.jsx` |
| 휴대폰 헤더 | 520px 이하에서 노선 메뉴를 "탐색·예약·스토어·마이"로 줄여 한 줄에 | `components/layout/Site.jsx`, `styles/components.css` |
| 휴대폰 상단 영역 | 일러스트가 화면을 다 차지하지 않게 크기 제한, 마이페이지·반려동물 화면은 일러스트 숨김 | `styles/components.css` |

## Day 12 · UX 개선 및 입력 폼 Validation 강화

| 항목 | 내용 | 화면 |
|---|---|---|
| 비밀번호 조건 체크 | 입력하는 동안 8~20자 · 영문 · 숫자 · 특수문자를 하나씩 초록으로 | 회원가입 |
| Caps Lock 경고 | 비밀번호 칸에서 Caps Lock이 켜져 있으면 안내 | 로그인, 회원가입 |
| 첫 오류 칸으로 이동 | 제출이 막히면 첫 번째 잘못된 칸으로 스크롤 + 커서 | 회원가입, 로그인, 비밀번호 찾기, 반려동물, 리뷰 |
| 서버 오류를 칸에 표시 | 서버가 `pets[0].weight` 처럼 알려준 오류를 해당 반려동물 칸 아래에 | 회원가입 |
| 체중 입력 정리 | 숫자·소수점 한 자리만, 100kg 이하 (`18.55kg` → `18.5`, `18.` 도 허용) | 회원가입, 반려동물 추가·수정 |
| 이메일 공백 제거 | 칸을 벗어나면 앞뒤 공백 자동 제거 | 회원가입 |
| 작성 중 이탈 경고 | 입력하다가 새로고침·탭 닫기 → 브라우저 확인창 | 회원가입, 반려동물 추가·수정 |
| 리뷰 닫기 확인 | 쓰던 리뷰가 있으면 "지금 닫으면 입력한 내용이 사라져요" | 장소 상세, 마이페이지 |
