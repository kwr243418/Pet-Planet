# FE1 통합 UI 테스트 체크리스트 (v2 — 팀 목업 기준)

## 자동 테스트
```bash
npm run test:unit   # node 내장 테스트러너, 추가 설치 없음
```
- `tests/utils.test.js` — 하버사인 거리, 도보 시간, 입력 검증, 크기 판정, km 표기
- `tests/flow.test.js` — 목 서버로 시연 시나리오 검증: 카테고리 4종 · 노선 순서 · 홍대입구 0.3/0.6/0.7/0.9km · 0.5km 필터 · 실내 필터 · 리뷰 많은 순 · 계정+반려동물 동시 가입(트랜잭션 롤백) · 중복 찜 409 · 리뷰 작성·중복·수정·삭제 · 요약 타일 · 회원정보 수정 · 탈퇴 · 401/403/404

## 수동 체크리스트 (`VITE_USE_MOCK=false` 로 실제 API에 대해)

### 공통 (목업 규칙)
- [ ] 헤더: 현재 노선 메뉴만 흰 배경 (E: 탐색·상세, M: 마이·가입)
- [ ] 선택 버튼은 베이지 바탕 + 흰 알약, 어두운 채움으로 선택 표시 없음
- [ ] 화면마다 짙은 초록 채움 버튼은 주요 동작 1개
- [ ] 푸터 출처 문구 · E R S M 표시
- [ ] 폰트: 메인 PET PLANET 타이틀만 Bagel Fat One, 영문 제목 Jost, 한글 Gothic A1

### S01 메인 홈
- [ ] [우리 역 주변 찾기] → 마지막으로 본 역(처음엔 홍대입구) 탐색 화면
- [ ] E·R·S·M 타일 이동, "이번 역은 ○○역입니다" 카드 3개(거리 km·장소명·크기·실내외)
- [ ] 체중 배너: 로그인+반려동물 있으면 내 아이 체중으로 입실 가능/불가, 없으면 예시(보리 18kg)

### S02 역세권 탐색
- [ ] 1~9호선 중 1개 선택, [전체 노선 보기]로 신분당·수인분당·경의중앙·공항 표시
- [ ] 호선 바꾸면 직전 역과 가장 가까운 역이 자동 선택, 노선도에서 선택 역만 크게
- [ ] 필터: 카테고리 여러 개 · 크기 · 실내/실외 · 0.5km/1km · 초기화 → 결과 수 변경
- [ ] 제목 "○○역 반경 1km", 정렬(가까운 순/리뷰 많은 순)
- [ ] 카드 번호와 지도 핀 번호 일치, 핀 클릭 → 카드 강조, 카드 hover → 핀 강조
- [ ] 결과 0건 → 빈 화면 + 필터 초기화
- [ ] 새로고침/뒤로가기 후에도 호선·역·필터 유지 (URL)
- [ ] 카카오맵 키 설정 시 실제 지도(반경 원·역·번호 핀), 키 없으면 미리보기 지도

### S03 장소 상세
- [ ] 경로 "호선 › 역 › 카테고리" (탐색에서 들어온 호선·역 유지)
- [ ] 칩(카테고리·크기·실내외), 별점+리뷰 수, 주소·전화
- [ ] [관심 장소 찜하기] → "찜한 장소예요", 다시 누르면 해제, 비로그인 → 로그인 후 복귀
- [ ] 같은 장소 중복 찜 시 서버 409 → 화면은 찜 상태 유지
- [ ] [카카오맵 길찾기] 새 탭
- [ ] 가까운 지하철역 카드(가장 가까운 역 짙은 초록), 클릭 → 그 역 탐색
- [ ] 방문 후기: 별점 미선택/10자 미만 에러, 등록 후 평균·개수 갱신, 내 리뷰만 [수정]·[삭제]
- [ ] 환승 배너 → 펫 스토어

### S09 회원가입
- [ ] 중복 확인 안 하면 가입 불가, 이미 있는 이메일 → 에러 문구
- [ ] 회원 유형 일반/사업자 (관리자 없음)
- [ ] 반려동물 필수 5개(이름·품종·체중·성별·중성화) 미입력 시 각 칸 에러
- [ ] 사진 선택 → 미리보기, 10MB 초과·이미지 아님 → 에러
- [ ] [+ 반려동물 더 등록하기] 최대 5마리, 추가분 삭제
- [ ] 반려동물 칸에 들어가면 NOW STATION이 "반려동물 등록"으로
- [ ] 가입 성공 → 홈, 헤더에 "○○ 님"

### S08 마이페이지
- [ ] 이름·회원 유형·이메일, [회원정보 수정] 모달 (이름만 수정)
- [ ] 요약 타일 4개 숫자, 누르면 해당 영역으로 스크롤
- [ ] 반려동물 카드(이름·품종·성별·중성화·체중) → 수정/삭제, [+ 반려동물 추가]
- [ ] 작성한 리뷰: 전체/장소/상품 필터, 수정·삭제
- [ ] 찜한 장소: 호선·역·거리, 하트로 찜 해제
- [ ] 회원 탈퇴 안내 문구, 탈퇴 → 홈 (진행 중 예약/주문 있으면 409 메시지)
- [ ] 예약 현황 · 주문 내역은 FE2 연결 후 확인

### 예외 처리
브라우저 콘솔에서 목 서버 강제 에러:
```js
localStorage.setItem('pp-mock-fail', 'network') // 또는 '500'
localStorage.removeItem('pp-mock-fail')
```
- [ ] 네트워크 끊김 → "연결이 끊겼어요" + 다시 시도
- [ ] `/places/9999` → 404 안내 + 다른 장소 둘러보기
- [ ] 없는 경로 → "없는 역이에요"
