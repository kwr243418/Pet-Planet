# 07. 시연 시나리오 · 통합 테스트

일정표 "최종 시연 핵심 시나리오"(Day 13~15)를 목업 화면에 맞춰 풀어 쓴 거예요. Day 5·10·13 통합 점검 때 이 순서로 확인해요.

## 시연 5단계

| 단계 | 시나리오 | 화면 | 담당 | 확인할 것 |
|---|---|---|---|---|
| 1 | 회원가입 & 로그인 | S09 → S01 | FE1·BE1 | 이메일 중복 확인, 계정+첫 반려동물 한 번에 가입, 홈 체중 배너에 내 반려동물 |
| 2 | 지하철역 & 장소 탐색 | S01 → S02 → S03 | FE1·BE1 | 2호선 › 홍대입구(또는 강남) 선택, 카페·식당 + 소형 필터, 지도 핀 번호, 장소 찜(중복 불가) |
| 3 | 병원 예약 | S04-0 → S04 → S08 | FE2·BE2 | 병원 리뷰 확인 → 반려동물·일시 선택 → 신청(승인대기) → 상태 변경(예약확정) → 마이페이지 예약 현황 |
| 3+ | 호텔 예약 | S05 | FE2·BE2 | 18kg 반려동물 → 15kg 객실 "입실 불가", 30kg 객실 선택, 기간 중복 막힘 |
| 4 | 쇼핑 | S06 → S07 → S08 | FE2·BE2 | 같은 상품 두 번 담기 → 수량 합쳐짐, 가상 결제 → 재고 차감·장바구니 비움, 재고 부족 시 전체 취소 |
| 5 | 통합 리뷰 & 별점 | S03 · S04-0 · S08 | 모두 | 장소 리뷰 작성 → 평균 별점 바로 반영, 이용완료 병원·배송완료 상품만 리뷰 가능, 마이페이지 작성한 리뷰(장소·상품) |
