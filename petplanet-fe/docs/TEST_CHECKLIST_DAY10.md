# Day 10 — 장소 탐색 / 북마크 / 리뷰 통합 UI 테스트 체크리스트

## 자동 테스트
```bash
npm run test:unit   # node 내장 테스트러너 — 추가 설치 없음
```
- `tests/utils.test.js` — 하버사인 거리, 도보 시간, 입력 검증, 크기 판정, 포맷터
- `tests/flow.test.js` — 목 서버로 **시연 시나리오 전체** 검증: 회원가입 → 반려동물 등록 → 강남역 검색 → 반경 1km/정렬 → 다중 필터 → 페이지네이션 → 찜/해제 → 리뷰 작성·중복·수정·삭제 + 401/403/404

> BE1 API 연동 후에는 같은 시나리오를 아래 수동 체크리스트로 실제 서버에 대해 한 번 더 확인하세요.

## 수동 체크리스트 (VITE_USE_MOCK=false 로 실제 API에 대해)

### 회원
- [ ] 첫 방문 시 스플래시 → 워크스루 → 로그인 이동
- [ ] 빈 값 로그인 → 각 칸 아래 에러 / 틀린 비밀번호 → "이메일 또는 비밀번호가 일치하지 않아요"
- [ ] 회원가입: 중복확인 안 하면 가입 불가, 이미 있는 이메일 → 빨간 메시지
- [ ] 비밀번호 규칙(영문·숫자·특수 8~20), 비밀번호 확인 불일치 메시지
- [ ] 가입 직후 반려동물 등록 화면 → "나중에 할게요" 가능
- [ ] 새로고침해도 로그인 유지(`/auth/me`), 토큰 만료(401) 시 로그인 화면으로 이동 + 토스트
- [ ] 비밀번호 찾기: 정보 불일치 시 에러, 성공 시 마스킹된 이메일 표시

### 반려동물
- [ ] 몸무게 0, 101, 3.85 입력 시 에러 / 입력에 따라 소형·중형·대형 배지 변경
- [ ] 수정·삭제 후 마이페이지와 홈 인사말에 반영

### 장소 탐색 (D4·D6·D9)
- [ ] "강남", "강남역" 둘 다 자동완성 / 없는 역 → 안내 문구 / ↑↓ Enter 동작
- [ ] 최근 검색 역이 포커스 시 표시
- [ ] 역 선택 → 지도에 1km 원 + 역 마커 + 장소 마커, 목록은 가까운순
- [ ] 마커 클릭 → 해당 카드 강조 + 스크롤 / 카드 hover → 마커 강조
- [ ] 카테고리 칩 다중 선택, 필터 시트(호선·크기·실내외) 적용 → 결과 수 변경, 적용된 조건 칩 ✕로 해제
- [ ] 조건 결과 0건 → 빈 화면 + 필터 초기화 버튼
- [ ] 필터 상태가 URL에 남아 새로고침/뒤로가기 후에도 유지
- [ ] 10개 넘으면 "장소 더 보기"
- [ ] 카카오맵 키 설정 시 실제 지도, 키 없거나 도메인 미등록 시 미리보기 지도로 자동 대체

### 상세 / 찜 / 리뷰 (D7·D8)
- [ ] 대표 반려동물 크기 기준 "함께 갈 수 있어요 / 어려울 수 있어요" 표시
- [ ] 인접역 클릭 → 그 역 기준 탐색 화면
- [ ] 비로그인 찜/리뷰 → 로그인 화면 → 로그인 후 원래 상세로 복귀
- [ ] 찜 토글 즉시 반영, 서버 실패 시 원래대로 되돌아가고 토스트
- [ ] 찜 목록에서 하트 해제 → 목록에서 제거
- [ ] 리뷰: 별점 미선택/10자 미만 → 에러, 빠른 태그 버튼으로 문구 추가, 500자 카운터
- [ ] 리뷰 등록 후 평균 별점·분포·개수 즉시 갱신, "내 리뷰" 표시
- [ ] 같은 장소 두 번째 리뷰 → 수정 화면으로 열림 (서버 409도 처리)
- [ ] 내 리뷰 수정/삭제 확인창, 정렬(최신·별점 높은·낮은) 동작

### 예외 처리 (D5)
목 서버에서 강제로 에러를 내려면 브라우저 콘솔에서:
```js
localStorage.setItem('pp-mock-fail', 'network') // 또는 '500'
localStorage.removeItem('pp-mock-fail')          // 해제
```
- [ ] 네트워크 끊김 → "연결이 끊겼어요" + 다시 시도 버튼
- [ ] 500 → "서버에 잠시 문제가 생겼어요"
- [ ] 없는 장소 `/places/9999` → 404 안내 + 다른 장소 둘러보기
- [ ] 없는 경로 → 404 화면
